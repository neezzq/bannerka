# Сайт заказов докладов и презентаций

- **/** — сайт для клиентов: ориентировочные цены за весь проект, форма заявки, кнопка поддержки в Telegram.
- **/admin** — админка: заявки, цены и все тексты страницы, итоги по месяцам. Вход по паролю из `.env`.
- **Telegram-бот** — присылает каждую новую заявку, кнопки «В работу / Сдан / Отменить», команда `/orders`.
- **Оплата через ЮKassa** — полная сумма заказа онлайн: карта, СБП, SberPay. Оплата сама попадает в «Оплачено».

Всё работает на вашем сервере: один Docker-контейнер на Node.js, без баз данных и внешних сервисов.
Заявки и настройки хранятся в папке `data/` (`orders.json`, `config.json`).

## Файлы

| Файл | Что это |
|---|---|
| `index.html`, `admin.html`, `app.css` | Страницы и стили |
| `common.js` | Расчёт цены и проверка заявки (один и тот же код на сайте и на сервере) |
| `server/server.js` | Сервер: страницы, API `/api`, хранение заявок, Telegram-бот |
| `docker-compose.yml` | Запуск контейнера на `127.0.0.1:18081` |
| `.env.example` | Образец настроек: пароль, токен бота |
| `config.js` | `API_URL: '/api'` (пустая строка — демо-режим без сервера, пароль `demo`) |

## Установка на сервер

```bash
cd /var/www/bannerka
cp .env.example .env
nano .env                       # ADMIN_PASSWORD, TG_TOKEN
sudo docker compose up -d
curl http://127.0.0.1:18081/api # {"ok":true,"message":"API работает"}
```

В Caddy для домена: `reverse_proxy 127.0.0.1:18081`.

## Сменить пароль

```bash
cd /var/www/bannerka && nano .env
sudo docker compose up -d --force-recreate
```

После смены пароля бот перестанет слать уведомления в старые чаты — снова напишите ему `/login новый_пароль`.

## Telegram-бот

1. [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Впишите его в `.env` как `TG_TOKEN=...` и перезапустите контейнер.
3. Напишите своему боту `/login ваш_пароль` (сообщение с паролем бот сразу удалит).

Команды: `/orders` — активные заявки, `/logout` — отключить уведомления.

## Оплата через ЮKassa

1. В [личном кабинете ЮKassa](https://yookassa.ru/my) → **Интеграция → Ключи API** возьмите `shopId` и выпустите секретный ключ.
2. Впишите их в `.env` (`YK_SHOP_ID`, `YK_SECRET_KEY`). Если ЮKassa отправляет чеки за вас — `YK_RECEIPT=1`.
3. **Интеграция → HTTP-уведомления**: адрес `https://banerka.ru/api/yookassa`, отметьте событие `payment.succeeded`.
4. Перезапустите контейнер.

Как платит клиент:
- сразу после заявки — кнопка «Оплатить N ₽»;
- позже — по ссылке на оплату (кнопка «💳 Ссылка на оплату» в карточке заказа или строка в уведомлении бота).

Оплачивается всегда полная цена заказа минус уже оплаченное. Если вы поменяли цену в админке, ссылка сама покажет новую сумму.
После оплаты сумма прибавляется к «Оплачено», статус «Новый» меняется на «В работе», а бот пишет «💳 Оплата».

## Цена

```
итог = цена услуги (за весь проект) + опции + (если до срока меньше N дней: X% от цены услуги)
итог округляется до 10 ₽
```

Сервер пересчитывает цену сам — подделать сумму из браузера нельзя.
