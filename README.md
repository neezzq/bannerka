# Сайт заказов докладов и презентаций

Две части:

- **index.html** — страница для клиентов: цены, форма заявки, расчёт цены сразу при заполнении.
- **admin.html** — ваша админка: заявки, цены, итоги по месяцам. Вход по паролю.

Данные хранятся бесплатно, без своего сервера: в Google Таблице через Google Apps Script.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Страница для клиентов |
| `admin.html` | Админка |
| `app.css` | Стили |
| `common.js` | Общая логика: расчёт цены, запросы к API, демо-режим |
| `config.js` | Сюда вставляется ссылка на скрипт (`API_URL`) |
| `manifest.json`, `admin-manifest.json` | Два отдельных «приложения» для экрана «Домой» |
| `sw.js` | Service worker: сначала сеть, без сети — кэш |
| `icons/` | Иконки 192/512 и apple-touch-icon 180×180 (для сайта и для админки) |
| `Code.gs` | Код для Google Apps Script (на сайт выкладывать не нужно) |

## Демо-режим

Пока в `config.js` пустой `API_URL`, сайт работает в демо-режиме: сверху плашка «Демо-режим», заявки и цены хранятся только в этом браузере, пароль админки — **demo**. Так можно всё посмотреть ещё до настройки Google.

## Пошаговая настройка

### 1. Создайте Google Таблицу

1. Откройте [sheets.new](https://sheets.new) (нужен Google-аккаунт).
2. Назовите таблицу, например, «Заказы докладов».

Лист «Заказы» скрипт создаст сам.

### 2. Вставьте скрипт

1. В таблице откройте меню **Расширения → Apps Script**.
2. Удалите всё в файле `Код.gs` (`Code.gs`) и вставьте туда содержимое файла **Code.gs** из этого проекта.
3. Нажмите 💾 «Сохранить».
4. Сверху в списке функций выберите **setup** и нажмите **▶ Выполнить**.
5. Google попросит разрешения: **Проверить разрешения → ваш аккаунт → Дополнительные настройки → Перейти к проекту (небезопасно) → Разрешить**. Это ваш собственный скрипт, это нормально.
6. В таблице появится лист «Заказы» с заголовками.

### 3. Задайте пароль от админки

1. В Apps Script слева нажмите ⚙️ **Настройки проекта**.
2. Внизу, в разделе **Свойства скрипта**, нажмите **Добавить свойство скрипта**.
3. Свойство: `ADMIN_PASSWORD`, значение — ваш пароль (лучше длинный, 10+ символов).
4. Нажмите **Сохранить свойства скрипта**.

Там же, в настройках проекта, проверьте **Часовой пояс** — по нему считаются «сегодня» и срочность.

### 4. Опубликуйте как веб-приложение

1. Вверху справа: **Начать развертывание → Новое развертывание**.
2. Шестерёнка «Выберите тип» → **Веб-приложение**.
3. Заполните:
   - Описание: любое, например «v1»;
   - **Запуск от имени: Я**;
   - **У кого есть доступ: Все**.
4. Нажмите **Начать развертывание** и скопируйте **URL веб-приложения** (заканчивается на `/exec`).

Проверка: откройте эту ссылку в браузере — должно появиться `{"ok":true,"message":"API работает..."}`.

> **Важно:** если вы потом меняете код в `Code.gs`, нужно **Начать развертывание → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть**. Ссылка при этом останется прежней. Цены и тексты менять через код не нужно — это делается в админке.

### 5. Вставьте ссылку в config.js

Откройте `config.js` и вставьте ссылку между кавычками:

```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/AKfy.../exec'
};
```

### 6. Выложите сайт на Netlify Drop

1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите в окно **папку с сайтом** (все файлы и папку `icons`). `Code.gs` можно убрать — сайту он не нужен (секретов в нём нет).
3. Через несколько секунд появится адрес вида `https://что-то.netlify.app`.
4. Чтобы сайт не удалился через час и чтобы потом обновлять его по тому же адресу, зарегистрируйтесь (бесплатно) и нажмите **Claim site**. В **Site configuration → Change site name** можно задать понятное имя.
5. Обновить сайт: **Deploys** → перетащите папку ещё раз.

Ссылки:
- для клиентов — `https://ваш-сайт.netlify.app/`
- админка — `https://ваш-сайт.netlify.app/admin.html` (никому её не давайте)

Откройте админку, введите пароль, зайдите во вкладку **«Цены»**, проверьте цены и тексты (особенно «Мой контакт») и нажмите **«Сохранить»**.

### 7. Добавьте на экран «Домой» на iPhone

Сайт и админку можно установить как два отдельных приложения — у них разные иконки и названия.

1. Откройте ссылку **в Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Пролистайте и выберите **«На экран „Домой“»** → **«Добавить»**.
4. Повторите для `admin.html` — появится второе приложение «Заказы».

В админке пароль запоминается на устройстве, вводить его каждый раз не придётся. Кнопка выхода — справа вверху.

### 8. Уведомления о заявках в Telegram

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и username (должен заканчиваться на `bot`).
2. BotFather пришлёт **токен** вида `123456789:AA...` — никому его не показывайте.
3. Найдите своего нового бота и напишите ему `/start` (иначе бот не сможет вам писать).
4. В Apps Script → ⚙️ **Настройки проекта** → **Свойства скрипта** добавьте `TG_TOKEN` = токен.
5. Узнайте свой chat_id: в редакторе выберите функцию **showTelegramChatId** → **▶ Выполнить**. В журнале появится строка `chat_id: 123456789 — ...`.
   (Или напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш Id.)
6. Добавьте свойство `TG_CHAT_ID` = этот номер.
7. Выберите функцию **testTelegram** → **▶ Выполнить**. Должно прийти сообщение «Уведомления о заявках подключены!».

Переразвёртывать скрипт после добавления свойств не нужно — новые заявки сразу начнут приходить в Telegram: номер, имя, контакт, услуга, объём, тема, срок, опции, пожелания и сумма.

## Как это работает

**Цена:**

```
база  = max(цена_за_единицу × объём, минимальная_стоимость)
итог  = база + выбранные опции + (если до срока меньше N дней: X% от базы)
итог округляется до 10 ₽, предоплата = P% от итога (тоже до 10 ₽)
```

Сервер пересчитывает цену сам по той же формуле — подделать сумму из браузера нельзя.

**Защита:**
- обязательные поля и длина строк проверяются на сервере;
- значения, начинающиеся с `= + - @`, записываются как текст (защита от формул в таблице);
- не больше 5 заявок с одного контакта в час;
- скрытое поле-ловушка для ботов;
- при неверном пароле — задержка, растущая с числом попыток;
- запись в таблицу — под блокировкой (LockService), чтобы одновременные заявки не перепутались.

**Таблица «Заказы»:** одна строка — одна заявка, все колонки текстом. Редактировать удобнее в админке; если правите таблицу вручную, не меняйте порядок колонок и номера в колонке «№».

**Статусы:** Новый, В работе, На правках (это «активные»), Сдан, Отменён.

## Частые проблемы

- **«Сервер вернул непонятный ответ»** — проверьте, что в развертывании стоит доступ «Все», а ссылка заканчивается на `/exec`.
- **«Пароль не задан»** — добавьте свойство `ADMIN_PASSWORD`.
- **Изменения в Code.gs не работают** — создайте новую версию развертывания (шаг 4).
- **На сайте старая версия** после обновления — закройте и откройте приложение ещё раз (service worker берёт свежие файлы из сети, кэш нужен только без интернета).
